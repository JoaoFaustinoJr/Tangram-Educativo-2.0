Aula 47 — Como o computador toma decisões?

Tipos de dados, booleanos e condicionais em Python

1. Descobrir2. Entender3. Ver4. Experimentar5. Explicar

1. O que vamos aprender?

Você vai aprender como um jogo decide quando mostrar um aviso. Ao final, conseguirá explicar o que são condições verdadeiras e falsas e alterar um pequeno programa.

Imagine que a RAI precisa entregar uma encomenda antes de o relógio zerar. Quando faltam menos de 60 segundos, o jogo deve mostrar: Missão rápida!

Pergunta: como ensinar essa regra ao computador?

2. Entenda antes de programar

Uma variável é um nome que guarda uma informação, como tempo = 45. Esse valor é um número inteiro (int). Já uma mensagem entre aspas é texto (str).

Uma comparação, como tempo < 60, pergunta se o tempo é menor que 60. A resposta só pode ser True (verdadeiro) ou False (falso): isso é um booleano (bool).

O comando if significa se. O comando else significa caso contrário. O computador executa o bloco correspondente à resposta da comparação.

💡 RAI explica de outro jeito

É como uma regra de trânsito: se o sinal está vermelho, pare; caso contrário, siga somente quando for seguro. O programa também verifica uma condição antes de agir.

2A. Os quatro tipos de informação

O computador precisa saber que tipo de informação está armazenando. Um inteiro (int) representa quantidades sem parte decimal, como 45 segundos. Um decimal (float) representa medições como 23.5 °C. Uma string (str) representa textos como "Alerta". Um booleano (bool) representa apenas verdadeiro ou falso.

vidas = 3             # int\ntemperatura = 23.5   # float\nmensagem = "Olá"     # str\nporta_aberta = False # bool\n\nprint(type(vidas))

O comando type() revela o tipo de um valor. Observe: "3" é texto, enquanto 3 é um número. Eles não têm o mesmo significado para o programa.

Investigue: por que o tipo importa?

Imagine que um sensor envie a temperatura como texto. Antes de comparar essa leitura com um número, pode ser necessário convertê-la usando float(). O tipo correto evita erros e permite cálculos.

2B. Como funcionam as comparações?

Uma comparação verifica uma relação entre dois valores. Seu resultado é booleano: verdadeiro ou falso.

  • < menor que; > maior que
  • <= menor ou igual; >= maior ou igual
  • == igual a; != diferente de

Atenção: = atribui um valor à variável; == compara dois valores.

tempo = 60\nprint(tempo < 60)   # False\nprint(tempo <= 60)  # True\nprint(tempo == 60)  # True

Repare que o número 60 é o limite. A escolha entre < e <= muda o comportamento exatamente nesse ponto.

3. Veja o exemplo resolvido

tempo = 45

if tempo < 60:
    print("Missão rápida!")
else:
    print("Continue a missão!")

Linha 1: guarda 45 na variável tempo. Linha 3: compara 45 com 60. Como 45 é menor, a condição é verdadeira. Linha 4: mostra “Missão rápida!”. O bloco else não é executado.

Observe os espaços antes de print: a indentação indica quais comandos pertencem a cada bloco.

3A. Entenda o fluxo da decisão

O Python executa as instruções de cima para baixo. Quando encontra if, calcula a condição. Se for verdadeira, executa o bloco indentado abaixo do if. Caso contrário, ignora esse bloco e, se houver else, executa o outro.

Passo a passo com 45 segundos: (1) lê o valor 45; (2) avalia 45 < 60; (3) obtém True; (4) executa somente o primeiro print.

Passo a passo com 80 segundos: (1) lê o valor 80; (2) avalia 80 < 60; (3) obtém False; (4) executa o print do else.

Erro comum: esquecer os dois-pontos ou os espaços
if tempo < 60:\n    print("Missão rápida!")

Os dois-pontos iniciam o bloco e os quatro espaços indicam que a linha pertence ao if. Sem a indentação correta, o Python pode apresentar erro.

4A. Três situações reais para aplicar

🤖 Robô e bateria

Um robô deve avisar quando a carga estiver abaixo de 20%. Com bateria = 15, a comparação 15 < 20 é verdadeira. Com 20%, não é.

bateria = 15\nif bateria < 20:\n    print("Recarregar robô")\nelse:\n    print("Pode continuar")

🌱 Irrigação inteligente

Uma estufa pode usar a leitura de um sensor de umidade do solo para decidir quando ligar uma bomba. Neste exemplo didático, adotamos um limite hipotético de 30% — na prática, o limite depende da cultura e do sensor.

umidade = 25\nif umidade < 30:\n    print("Solicitar irrigação")\nelse:\n    print("Umidade suficiente")

🚦 Sensor de distância

Um robô detecta um obstáculo a 12 cm. Se a distância for menor que 15 cm, ele deve parar. Em um robô real, o sensor e o controle do motor precisam estar corretamente conectados e programados.

distancia = 12\nif distancia < 15:\n    print("Parar motor")\nelse:\n    print("Caminho livre")

Compare os exemplos: a estrutura do algoritmo é a mesma. O que muda são as variáveis, os limites e as ações.

🔍 Precisa de uma pista?

5A. Desafio de raciocínio e depuração

Um colega escreveu o código abaixo para avisar quando o tempo for menor ou igual a 60 segundos. Entretanto, ele utilizou o operador errado:

tempo = 60\nif tempo < 60:\n    print("Alerta")

Desafio: identifique o problema, corrija o operador e explique por que a mensagem não aparecia quando o tempo era exatamente 60.

Conferir explicação depois de tentar

O operador correto é <=. Ele inclui o valor 60. O operador < exclui esse limite.

Para ir além: várias decisões

Quando existem mais de dois caminhos, podemos usar elif, que significa “senão, se”.

tempo = 35\nif tempo < 20:\n    print("Urgente!")\nelif tempo < 60:\n    print("Acelere!")\nelse:\n    print("Tempo suficiente")

O Python testa as condições na ordem e executa o primeiro bloco cuja condição for verdadeira.
