# Tangram Educativo 2.0

Nova geração do Tangram Educativo — Prof. João Faustino Júnior.

## Direção
Interface limpa, moderna e responsiva, inspirada na linguagem visual do X1 Arena. O jogo é o elemento principal; conteúdos pedagógicos como **Matemática em jogo** aparecem sob demanda.

## v2.0.0 — base
- Desafio 1 visível na abertura
- área de tabuleiro e bandeja com 7 peças
- controles Girar, Espelhar, Dica, Amostra e Ampliar
- acessos X1 Arena, Gamer e Aulas
- Matemática em jogo recolhível
- estrutura preparada para desafios, progresso e conquistas

> O Tangram original permanece separado como versão estável.
