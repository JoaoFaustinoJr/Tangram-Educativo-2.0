Planilhas: investigando dados do cotidiano

Educação Digital · 9º ano · Aula 3

1 · Descubra

Uma planilha organiza dados em colunas (letras), linhas (números) e células (encontros entre ambas). B2 significa coluna B, linha 2.

RAI: “Organizar dados é o primeiro passo para descobrir padrões!”
