1. Revisão resumida do ano

1. Pensamento computacional e algoritmos

Decompor é dividir problemas; reconhecer padrões é encontrar semelhanças; abstrair é selecionar o que importa; criar um algoritmo é organizar passos. Antes de programar, descreva as entradas, as ações e o resultado esperado.

2. Python: entrada e saída

Python é uma linguagem de programação. print() exibe informações; input() recebe texto digitado. Exemplo: nome = input("Nome: "). Depois, print(nome) mostra o valor recebido. Podemos praticar esses comandos em um notebook de programação, como o Colab.

3. Variáveis e tipos de dados

Variáveis guardam valores. int representa inteiros, como 12; float, números decimais, como 7.5; str, textos, como "Olá"; bool, True ou False. O tipo influencia as operações possíveis.

4. Conversão e operações

input() devolve texto. Para calcular com um inteiro digitado, use int(input("Número: ")). float() pode converter um texto decimal escrito com ponto. Em Python, + soma números, mas junta textos: "2" + "3" produz "23"; 2 + 3 produz 5.

5. Comparações e lógica

Use == para comparar igualdade e = para atribuir um valor. != significa diferente; >, <, >= e <= comparam grandezas. and exige as duas condições verdadeiras; or exige ao menos uma; not inverte o valor lógico.

6. Condições e indentação

if testa uma condição; elif testa outra; else trata os demais casos. Os espaços no início da linha indicam quais comandos pertencem a cada bloco. Em “se pontos >= 6”, o valor 6 já satisfaz a condição.

7. Listas e índices

Uma lista guarda vários itens: frutas = ["maçã", "uva", "pera"]. O primeiro índice é 0: frutas[0] é "maçã". frutas[1:3] seleciona os índices 1 e 2; o limite final não entra. len(frutas) informa a quantidade de itens.

8. Manipulação de listas

append() acrescenta um item ao final; remove() remove a primeira ocorrência de um valor existente; pop() pode retirar um item pelo índice. Uma lista pode ser alterada durante o programa. Confira os índices e os valores antes de remover.

9. Repetição com for e range

for percorre os itens de uma sequência. range(3) produz 0, 1 e 2. Portanto, “for i in range(3)” executa seu bloco três vezes. enumerate(lista) permite percorrer itens junto com seus índices, começando em 0 por padrão.

10. Repetição com while

while repete enquanto uma condição for verdadeira. Em uma contagem regressiva, é preciso diminuir o contador para que a condição deixe de valer. Se nada permitir encerrar a condição, pode ocorrer uma repetição infinita.

11. Testes, depuração e aleatoriedade

Depurar é localizar e corrigir erros. Teste valores diferentes, incluindo os limites das condições. Sorteios comuns podem repetir resultados: sortear não garante valores únicos. Se um projeto exige números sem repetição, o algoritmo deve verificar os já escolhidos ou usar uma seleção sem reposição.

12. Internet e sistemas distribuídos

A internet conecta redes. Sistemas distribuídos repartem tarefas ou dados entre computadores. Um cliente solicita um recurso e um servidor responde. Os dados viajam em pacotes; DNS consulta endereços associados aos nomes de sites. Serviços de nuvem também dependem de computadores físicos.

13. Protocolos e segurança

Protocolos são regras de comunicação. HTTP é utilizado na web; HTTPS protege a comunicação com criptografia. TCP ajuda a entregar dados em ordem e recuperar perdas. HTTPS não prova que um conteúdo seja verdadeiro. Use senhas diferentes e verificação em duas etapas e desconfie de pedidos urgentes de dados.

14. Privacidade e termos de uso

Permissões indicam acessos solicitados por um aplicativo, como câmera ou localização. Termos de uso e políticas de privacidade explicam regras e tratamento de dados. Analise se uma permissão é necessária, evite exposição de informações pessoais e respeite a autorização para publicar imagens.

15. Algoritmos de recomendação, IA e vieses

Plataformas podem usar dados das interações para recomendar conteúdos. Isso influencia o que vemos. Vieses são tendências que podem favorecer ou prejudicar grupos ou resultados. Sistemas de IA podem reproduzir vieses e errar: confira fontes, contexto e evidências antes de confiar ou compartilhar.

16. Dados: média, mediana e ordenação

A média é a soma dividida pela quantidade de valores. A mediana é o valor central após ordenar os dados; com quantidade par, é a média dos dois centrais. Em 2, 3 e 10, a média é 5 e a mediana é 3. Ordenar ajuda a comparar valores e localizar posições.

17. Robótica, prototipagem e recursão

Sensores captam informações; controladores processam; atuadores realizam ações. Prototipar é construir uma versão, testar e melhorar, considerando medidas e tolerâncias. Na programação, recursão ocorre quando uma função chama a si mesma para resolver um problema menor; precisa de um caso de parada, como nas soluções da Torre de Hanói.

Interprete este programa em Python

contador = 3
while contador > 0:
    print(contador)
    contador = contador - 1

O programa mostra 3, 2 e 1, cada um em uma linha. Quando contador chega a zero, a condição deixa de ser verdadeira. Observe os espaços que indicam o bloco do while.
